# Project context

This is **Jellyvin**, a fork of [jellyfin/jellycon](https://github.com/jellyfin/jellycon)
— a Kodi add-on that acts as a thin frontend for a Jellyfin server.

## Where to find context

Durable, tool-agnostic knowledge for working in this repo lives in the
[`.ai/`](.ai/) folder. Read the relevant file(s) there before making changes:

- [`.ai/DEVELOPMENT.md`](.ai/DEVELOPMENT.md) — build & packaging (how `addon.xml`
  is generated, branding sources, the build command, known gotchas, linting).

Add new context docs to `.ai/` and link them here rather than scattering notes.

## Quick reminders

- **Do not hand-edit `addon.xml`** — it is generated by `build.py`. See
  [`.ai/DEVELOPMENT.md`](.ai/DEVELOPMENT.md).
- Build with the bundled venv: `./jellycon_env/bin/python build.py`.
